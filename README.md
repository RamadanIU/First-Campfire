# Первый костёр

Автономный 2D pixel-art симулятор эволюции цивилизации. В диком сгенерированном мире появляются двое —
мужчина и женщина. Игрок ничем не управляет: он смотрит, как через поколения стоянка у костра превращается в город.

- **Играть (живая сборка):** <https://ramadaniu.github.io/First-Campfire/> — обновляется после каждого слитого шага.
- **Дизайн-документ:** [`docs/gdd/`](docs/gdd/README.md)
- **Дорожная карта:** [`docs/ROADMAP.md`](docs/ROADMAP.md) — 161 шаг, 13 этапов
- **Что игра умеет сейчас:** [`docs/STATUS.md`](docs/STATUS.md)

## Как идёт разработка

Игру шаг за шагом создаёт ИИ в сессиях Claude Code. **Одна сессия — один шаг дорожной карты.**

### Что делает владелец

1. Открывает новую сессию в этом репозитории и пишет: **«Следующий шаг»** (или `/step`).
   Чтобы выполнить конкретный шаг — «Выполни шаг 1.4» (или `/step 1.4`).
2. В конце сессии получает отчёт простым языком, скриншоты и ссылку на pull request.
3. Смотрит скриншоты и, если всё устраивает, сливает pull request (кнопка **Merge**).
   Не устраивает — пишет замечания в той же сессии, она исправит.
4. Открывает следующую сессию. И так до конца карты.

Важно: следующий шаг начинается только после того, как pull request предыдущего слит, — иначе новая сессия
не увидит сделанного.

### Что делает сессия

Всё остальное: читает правила и состояние проекта, выполняет шаг, проверяет его тестами и скриншотами,
записывает прогресс, открывает pull request. Правила — в [`CLAUDE.md`](CLAUDE.md), подробный порядок —
в [`docs/PROCESS.md`](docs/PROCESS.md).

### Одноразовая настройка: живая сборка

Чтобы игра открывалась по ссылке выше, нужно один раз включить GitHub Pages:
**Settings → Pages → Build and deployment → Source: «GitHub Actions»**. После следующего слияния в `main`
игра опубликуется сама.

## Для разработки

Нужен Node.js 22.18 или новее.

```bash
npm install
npm run dev      # игра в браузере с горячей перезагрузкой
npm run check    # линтер, типы, тесты, дорожная карта, сборка
npm run next     # следующий шаг дорожной карты
```

Устройство кода — [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
