# 5. Ресурсы, производственные цепочки, экономика

## 5.1. Общие правила ресурсов

- Каждый ресурс — **физический предмет** на карте: лежит в куче, в корзине, на складе, в руках. Ничего не телепортируется: каждое бревно кто-то донёс. Это основа зрелищности и логистики.
- У предмета есть: вес (сколько можно унести), **порча** (срок хранения), качество (плохое / обычное / хорошее / превосходное / шедевр), стопка (сколько в одном тайле).
- Грузоподъёмность: руки — 1 стопка; корзина/заплечный короб — ×2; волокуша — ×3; тачка — ×4; телега с волом — ×12; лодка — ×20; баржа/корабль — ×60.
- Порча зависит от хранения: на земле под дождём ×3, под навесом ×1, в амбаре ×0,5, в погребе ×0,3, в леднике ×0,15; обработка (сушка, копчение, засолка, квашение) умножает срок на 4–10.

## 5.3. Ключевые производственные цепочки

**Хлеб (хребет экономики эпох I–V)**

Расчистка поля → вспашка (мотыга → рало → плуг с волом → тяжёлый плуг с лошадью) → посев (весна) → прополка и охрана от птиц (дети, пугало) → жатва (серп → коса) → снопы сушатся на поле → обмолот на току (цеп) → веяние → зерно в амбар → помол (зернотёрка: 1 человек кормит 4 → ручной жёрнов: 10 → водяная мельница: 150 → ветряная: 200) → мука → пекарня (тесто, печь) → хлеб → дом/рынок. Побочные продукты: солома (крыши, подстилка, корм), отруби (корм свиньям), мякина.

**Одежда**

Овца → стрижка (весна) → мытьё шерсти → чесание → прядение (веретено → прялка с колесом) → ткачество (вертикальный станок → горизонтальный) → валяние/сукновальня → крашение (красильня у реки: вода ниже по течению меняет цвет!) → портной → одежда. Параллельно: лён → теребление → мочка → трепание → прядение → полотно. Кожа: шкура → мездрение → дубление (кора дуба, вонь — дубильня выносится на окраину) → кожевник → сапожник/шорник.

**Металл**

Разведка (рудознатец находит выход жилы) → рудник (яма → шурф → штольня с крепями → шахта с воротом и водоотливом) → дробление и промывка → углежоги жгут уголь в кучах (лес вокруг тает на глазах) → плавильня (яма → горн с мехами → домница → доменная печь на водяном приводе) → слитки → кузня → изделие → точильщик. Бронза требует олова, которого рядом может не быть → **первая причина дальней торговли**.

**Строительство**

Дерево: рубка → обрубка сучьев → трелёвка (на плечах → волоком → на телеге → сплавом по реке) → лесопилка (топор и клин → двуручная пила на козлах → водяная пилорама) → брёвна/доски/дранка. Камень: каменоломня → блоки → каменотёс → тёсаный камень. Глина: карьер → формовка → сушка → обжиг → кирпич/черепица. Известь: известняк/раковины → обжиг → гашение → раствор.

**Керамика:** глина → отмучивание → лепка (жгутами → на круге) → сушка на полках под навесом → обжиг (костёр → яма → горн) → роспись/глазурь → горшки, кувшины, миски, амфоры → хранение еды (срок ×2), пивоварение, торговля.

**Знание:** шкуры → пергамент (или тряпьё → бумага) + сажа и камедь → чернила + гусиное перо → писец → свиток/книга → библиотека → школа → грамотные жители → быстрее наука и администрация.

**Пиво и вино:** ячмень → солод → варка → брожение в бочках → таверна. Вино: виноградник → сбор (осенний праздник) → давильня (топчут ногами — отличная анимация) → бочки → погреб.

## 5.4. Хранение и логистика

Эволюция хранения: куча на земле → навес → яма-погреб → амбар на столбах (от мышей) → общинный склад → специализированные склады (зерновой, дровяник, ледник, арсенал) → купеческие лабазы → портовые пакгаузы.

Эволюция транспорта: руки → корзина → волокуша → собачья/ручная тележка → телега с волом → конная повозка → речная баржа → морское судно. Каждая ступень требует инфраструктуры: телеге нужна дорога шириной 2 тайла и мост вместо брода.

**Профессия носильщика/возчика** появляется, когда среднее расстояние «производство → склад» превышает порог: производителю выгоднее работать, а не носить.

Правило размещения складов: община ставит новый склад там, где сумма путей носильщиков минимальна (см. раздел 6).

## 5.5. Эволюция экономики

| Стадия | Эпоха | Как распределяются блага |
|--------|-------|--------------------------|
| **Общий котёл** | 0–I | Всё общее, едят у костра, инструменты берёт кто нужно. Нахлебников терпят, но отношения с ними портятся |
| **Домохозяйства** | I–II | У семьи свой очаг, запас, огород. Общие — амбар на чёрный день, поля, стадо. Появляется понятие «моё» |
| **Обмен и дар** | II | Ремесленник отдаёт горшки за зерно. Мерило — «мера зерна». Возникает понятие долга и репутации |
| **Рынок и монета** | III | Площадь с прилавками, цены плавают от спроса и предложения, появляется монета, купцы, налоги, жалованье |
| **Гильдии и кредит** | IV | Цеха регулируют качество и цены, ростовщики, ярмарки, пошлины, казна |
| **Банки и компании** | V | Вексель, банк, страхование, торговые компании, мануфактуры (разделение труда внутри мастерской) |

**Ценообразование (с эпохи III):** у каждого товара в поселении есть цена = базовая × (спрос / предложение)^0,5, сглаженная по времени. Жители с чертой «Честолюбивый» или «Жадный» замечают дорогой товар и переучиваются на его производство — рынок сам лечит дефицит, с задержкой в сезон-два. Наблюдатель видит это как «в городе вдруг открылись три пекарни».

**Неравенство** возникает само: удачливый род копит, строит дом побогаче, нанимает работников. Коэффициент неравенства отслеживается и питает социальные события (раздел 8): зависть, воровство, бунты, благотворительность, законы о долгах.

**Налоги и казна:** десятина зерном (эпоха II) → подати монетой (III) → пошлины и акцизы (IV) → бюджет с расходами на стражу, стены, дороги, школу, праздники (V). Высокие налоги — недовольство, низкие — грязь и слабая оборона.

**Внешняя торговля:** приходят караваны и корабли соседей; у каждого поселения свои излишки и дефициты (биом!). Торговля приносит товары, монету, семена новых культур, породы скота, технологии, моды — и болезни.
