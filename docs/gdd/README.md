# «ПЕРВЫЙ КОСТЁР» — дизайн-документ и план разработки

**Жанр:** 2D Pixel Art, автономный симулятор эволюции цивилизации (God Sim / Zero-Player Colony Sim)
**Рабочее название:** «Первый Костёр»
**Статус документа:** фундаментальный GDD + техническое задание + дорожная карта
**Версия:** 1.0

> Как читать документ. Разделы 1–2 задают каркас (принципы и устройство симуляции). Разделы 3–11 описывают игровые системы. Раздел 12 показывает, как системы сцеплены между собой. Раздел 13 фиксирует стартовые числа баланса. Раздел 14 — пошаговая дорожная карта. Раздел 15 — риски и критерии качества. Все числа — стартовые значения для настройки, а не догма: они нужны, чтобы у прототипа была точка опоры.

> **О разбиении.** Документ разбит на файлы по разделам, чтобы каждую сессию можно было читать только нужные части. Текст разделов не изменён. Рабочая дорожная карта разработки — в [`docs/ROADMAP.md`](../ROADMAP.md); раздел 14 ниже сохранён как исходный замысел.
