# Приложение. Краткий словарь

- **Доска нужд** — общий список проблем поселения, из которого жители берут задачи.
- **Износ** — счётчик проходов по тайлу, превращающий траву в тропу и дорогу.
- **Карта притягательности** — оценка каждого участка для каждого типа здания.
- **Вместимость культуры** — сколько технологий поселение способно удержать.
- **Носитель знания** — житель, владеющий технологией; без носителей и записей знание теряется.
- **Режиссёр событий** — скрытая система, выравнивающая темп потрясений через вероятности.
- **Уровни детализации** — полная, упрощённая и статистическая симуляция в зависимости от близости к камере.
- **Рацион** — еда одного взрослого на сутки, единица учёта продовольствия.
- **Сценка** — короткая анимационная ситуация, запускаемая условиями симуляции.
- **Веха** — эпохальное событие с торжественной подачей.
