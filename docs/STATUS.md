# Текущее состояние

> Снимок на конец шага **0.3**. Каждая сессия переписывает этот файл под новое состояние
> (это не история — история в `docs/journal/`).

## Что игра умеет

- **Заставка** — ночная стоянка с костром (временная графика прямоугольниками, до шага 0.4).
- **Ядро симуляции**: мир шагает тиками; одно зерно — одна история (проверено тестами). Календарь по GDD
  (сутки 400 тиков: рассвет, день, закат, ночь; сезон 3 дня; год 12 дней). Журнал событий с причинами.
- **Игровой цикл**: 10 тиков в секунду на ×1; скорости пауза / ×1 / ×2 / ×5 / ×20; защита от зависания.
- **Отладочная сцена `clock`**: небо по времени суток, дата, время, тик, скорость, журнал событий.
  Ночью летают светлячки — временная проверочная система со случайностью.
- **Графика как код** (шаг 0.3): спрайты — текстовые файлы `src/art/sprites/*.ts`, черновая палитра 32 цвета
  рядами, перекраска подменой рядов, атлас на одном холсте, проверка спрайтов тестами. Формат — `docs/ART.md`.
- **Сцена `gallery`**: все спрайты ×4, ×2, ×1, анимации, варианты перекраски, атлас; один спрайт крупно —
  `sprite=имя`. Спрайтов три: тайл травы `grass`, дерево `tree` (качается), житель `villager` (дышит; три тона кожи).

Жителей в мире, карты и настоящего мира ещё нет.

## Как это увидеть

| Что | Как |
|-----|-----|
| Локально | `npm run dev` |
| Заставка | `?scene=title` (сцена по умолчанию) |
| Ядро и календарь | `?scene=clock`; пробел — пауза, 1–4 — ×1, ×2, ×5, ×20 |
| Все спрайты | `?scene=gallery` |
| Один спрайт крупно | `?scene=gallery&sprite=villager` (или `tree`, `grass`) |

Параметры адресной строки: `scene` (сцена), `seed` (зерно), `ticks` (промотать мир до тика N до первого кадра),
`speed` (0, 1, 2, 5 или 20), `frame` (замороженный кадр: мир стоит, анимация остановлена на моменте N × 100 мс —
для одинаковых скриншотов), `ui=0` (скрыть интерфейс; в галерее — подписи), `sprite` (галерея: один спрайт).
Полезные тики: `tickAt(день, тик_дня)` в `src/sim/calendar.ts`; например день 5, полдень = `1740`, ночь дня 8 = `3130`.

## Устройство (кратко)

- `src/main.ts` — запуск: параметры, выбор сцены, цикл кадров (передаёт сцене время кадра и номер кадра показа,
  10 в секунду — `PRESENTATION_FPS` в `src/app/scene.ts`); готовность — `window.__fc`.
- `src/app/` — `params.ts` (адресная строка), `scenes.ts` (реестр сцен), `loop.ts` (игровой цикл), `controls.ts`
  (клавиши скорости), `titleScene.ts`, `clockScene.ts`, `galleryScene.ts`.
- `src/sim/` — ядро: `world.ts` (мир, шаг, порядок систем), `rng.ts`, `calendar.ts`, `events.ts`, `hash.ts`,
  `math.ts`, `systems/` (`calendarEvents`, `fireflies`). Подробно — `docs/ARCHITECTURE.md`, «Ядро симуляции».
- `src/art/` — графика как код: `palette.ts`, `sprite.ts` (формат и проверка), `raster.ts`, `atlas.ts`,
  `registry.ts`, `sprites/` (по файлу на спрайт). Чистые функции без браузера.
- `src/render/spriteSheet.ts` — атлас на холсте, рисование кадра по имени, кеш перекрашенных вариантов.
- `tools/` — `roadmap.ts`, `screenshot.ts`, `bench.ts` (замер скорости).
- `src/data`, `data/` — пока пустые.

## Известные проблемы

- Заставка и сцена `clock` нарисованы цветами прямо в коде, мимо палитры — до шага 0.4.
- Палитра черновая (32 цвета) — мастер-палитра на шаге 0.4.
- Журнал событий хранит всю историю без ограничения (≈ 6–7 событий в игровой день) — см. `BACKLOG.md`.
- Мелочи графики (повтор тайла на большом поле, дробный масштаб экрана, тени под объектами) — в `BACKLOG.md`.

## Как устроена работа (важно для каждой сессии)

- Проверок на GitHub (GitHub Actions) и публикации (живой сборки) нет и не будет — ADR-011. Не жди их и не трогай.
  Проверка — только `npm run check` в сессии.
- Свой PR сессия **сливает сама**, не спрашивая владельца (`docs/PROCESS.md`, раздел 5).

## Подсказки следующему шагу (0.4 — лист стиля)

- Формат спрайта и как добавить спрайт — `docs/ART.md`. Новый спрайт — один файл в `src/art/sprites/`; тест
  `src/art/sprites.test.ts` проверит его сам, галерея покажет сама.
- Мастер-палитра заменяет `RAMPS` в `src/art/palette.ts`. Ряды — от тёмного к светлому (тест), цвета не
  повторяются; ряды, которые подменяют друг друга (тона кожи, цвета волос), — одной длины. Если переименуешь
  ряды — поправь легенды трёх нынешних спрайтов (`tsc` и тесты покажут, где). Ряд `ui` нужен галерее (фон, клетки,
  крестик: `ui.0`–`ui.3`).
- Требование «все цвета спрайтов — из мастер-палитры (тест)» уже выполняется проверкой спрайта: цвет вне палитры
  записать нельзя.
- Сцену `palette` удобно сделать по образцу `galleryScene.ts` (HTML + маленькие холсты); `sprite=` — пример
  параметра сцены в `src/app/params.ts`.
- Нынешние `grass`, `tree`, `villager` — пробные; их можно перерисовать или переименовать (например,
  `villager` → мужчина/женщина с ходьбой в 4 направлениях). Зеркалить нельзя (свет слева-сверху), направления
  рисуются отдельно — `docs/ART.md`.
- Для рисования в сценах: `createSpriteSheet(SPRITES, PALETTE)` один раз, потом `sheet.draw(ctx, имя, x, y,
  { timeMs, scale, swap })` — точка привязки встаёт в (x, y). Анимации — по времени показа: `frame × 1000 /
  PRESENTATION_FPS`.
- Резкость на снимке можно проверить так, как в отчёте 0.3: снимок с `ui=0` должен содержать только цвета палитры.
- В `src/sim` нельзя `Math.sin/cos/exp/log/pow` и `**` — только `src/sim/math.ts` (ADR-009). Отрисовке можно всё.
- Числа времени пока в объекте `TIME` (`src/sim/calendar.ts`); на шаге 0.5 они переезжают в `data/balance.json`.
  В таблицах (0.5) спрайт указывается по имени; `src/data` не может импортировать `src/art` — проверку ссылок на
  спрайты делать тестом в `tests/` (он может импортировать оба).
