## Что игра умеет

- **Заставка** — ночная стоянка с костром (временная графика прямоугольниками, до шага 0.4).
- **Ядро симуляции**: мир шагает тиками; одно зерно — одна история (проверено тестами). Календарь по GDD
  (сутки 400 тиков: рассвет, день, закат, ночь; сезон 3 дня; год 12 дней). Журнал событий с причинами.
- **Игровой цикл**: 10 тиков в секунду на ×1; скорости пауза / ×1 / ×2 / ×5 / ×20; защита от зависания.
- **Отладочная сцена `clock`**: небо по времени суток, дата, время, тик, скорость, журнал событий.
  Ночью летают светлячки — временная проверочная система со случайностью.

Жителей, карты и настоящего мира ещё нет.

## Как это увидеть

| Что | Как |
|-----|-----|
| Локально | `npm run dev` |
| Заставка | `?scene=title` (сцена по умолчанию) |
| Ядро и календарь | `?scene=clock`; пробел — пауза, 1–4 — ×1, ×2, ×5, ×20 |

Параметры адресной строки: `scene` (сцена), `seed` (зерно), `ticks` (промотать мир до тика N до первого кадра),
`speed` (0, 1, 2, 5 или 20), `frame` (замороженный кадр: мир стоит, анимация не идёт — для одинаковых скриншотов),
`ui=0` (скрыть интерфейс). Полезные тики: `tickAt(день, тик_дня)` в `src/sim/calendar.ts`;
например день 5, полдень = `1740`, ночь дня 8 = `3130`.

Кадры, которые каждая сессия проверяет на отсутствие регрессий:

| Сцена | Параметры | Что должно быть видно |
|-------|-----------|-----------------------|
| Заставка | `?scene=title&frame=12` | Ночь, костёр со свечением, двое у огня, шалаш, название, без ошибок на странице |
| Часы, день | `?scene=clock&ticks=1740&frame=0` | «Год 1 · лето · день 2 из 3», 13:23, голубое небо и солнце, светлячков нет |
| Часы, ночь | `?scene=clock&ticks=3130&frame=0` | «осень · день 2», 00:47, луна и звёзды, светлячки над лугом; в журнале «вылетели светлячки: 16 ← #48 наступила ночь» |

## Устройство (кратко)

- `src/main.ts` — запуск: параметры, выбор сцены, цикл кадров (передаёт сцене время кадра); готовность — `window.__fc`.
- `src/app/` — `params.ts` (адресная строка), `scenes.ts` (реестр сцен), `loop.ts` (игровой цикл), `controls.ts`
  (клавиши скорости), `titleScene.ts`, `clockScene.ts`.
- `src/sim/` — ядро: `world.ts` (мир, шаг, порядок систем), `rng.ts`, `calendar.ts`, `events.ts`, `hash.ts`,
  `math.ts`, `systems/` (`calendarEvents`, `fireflies`). Подробно — `docs/ARCHITECTURE.md`, «Ядро симуляции».
- `tools/` — `roadmap.ts`, `screenshot.ts`, `bench.ts` (замер скорости).
- `src/data`, `src/render`, `src/art` — пока пустые.

## Известные проблемы

- Заставка и сцена `clock` нарисованы цветами прямо в коде, мимо палитры — до шага 0.4.
- Журнал событий хранит всю историю без ограничения (≈ 6–7 событий в игровой день) — см. `BACKLOG.md`.

## Подсказки следующему шагу (0.3 — графический конвейер)

- Шаг 0.3 не трогает симуляцию. Сцену `gallery` регистрируй в `src/app/scenes.ts` по образцу `clockScene.ts`
  (низкое разрешение в буфере + целочисленное увеличение, `imageSmoothingEnabled = false`).
- `src/art` зависит только от себя (направление зависимостей: `app → render → art`); растеризатор — чистая
  функция, чтобы работать и в Node (тесты), и в браузере.
- Анимации в галерее можно вести от номера кадра `frame` (как в заставке) — тогда `?frame=N` даёт одинаковый снимок.
- Для шагов с миром: мир создаётся `createWorld(seed)` + `runTicks(world, params.ticks)`, цикл — `createGameLoop`,
  отрисовка интерполирует между тиками через `loop.alpha` (пример — светлячки в `clockScene.ts`).
- В `src/sim` нельзя `Math.sin/cos/exp/log/pow` и `**` — только `src/sim/math.ts` (ADR-009). Отрисовке можно всё.
- Числа времени пока в объекте `TIME` (`src/sim/calendar.ts`); на шаге 0.5 они переезжают в `data/balance.json`.
- Для шага 0.7 (сохранения): состояние мира уже переживает JSON без потерь — есть тест «копия мира через JSON
  продолжает ту же историю» (`tests/determinism.test.ts`).
