# Шаг 1.6 — Панель наблюдателя: дата, скорость, события

**Дата:** 2026-11-18 · **PR:** #18

## Что сделано

- **Полоса сверху**: значок времени суток (солнце, восход, закат или месяц — пиксельные значки), дата «Год 2 · лето ·
  день 1 из 3», значок двоих и число жителей. Справа — кнопки **пауза, ×1, ×2, ×5, ×20** (нажатая — оранжевая; клавиши
  пробел и 1–4 делают то же) и **«Мир ▾»** — меню, куда переехала прежняя панель «Мир» (как сохранён, «Сохранить в
  файл», «В меню», клавиши, масштаб). Меню закрыто, угол карты свободен.
- **Лента событий** слева под полосой: пять последних значимых событий со значком и датой — пришли люди, «мужчина
  голодает», «женщина упала без сил», «умерла женщина — голод». **Щелчок по строке — камера плавно летит к месту**
  (0,8 с), и там на 3 секунды расходятся жёлтые кольца. Заголовок «События» сворачивает ленту.
- **Выбор жителя щелчком**: вокруг него — белые «дышащие» уголки рамки (видны и ночью), слева внизу — **карточка**: кто
  это, что делает, четыре шкалы (сытость, жажда, сон, здоровье) с числами. Щелчок мимо, × или Escape снимают выбор.
- **Телефон**: полоса в две строки, в ленте две последние строки, карточка внизу во всю ширину.
- **Единый модуль текстов** `src/ui/texts.ts`: все слова игры — меню, сохранения, даты, панель, события, отладочные сцены —
  теперь в одном месте; три копии подсчёта окончаний («2 года», «5 миров») заменены одной. Тест-сторож не даёт
  написать русскую строку в коде интерфейса мимо модуля.
- Мир и его история не изменились: отпечатки прогонов те же, что на 1.5.

## Проверки

- `npm run check`: зелёный (линтер, типы, 664 теста (на 1.5 — 644), дорожная карта, сборка).
- `npm run e2e`: все проверки пройдены, с новым сценарием «Панель наблюдателя: скорость, выбор жителя, лента событий»
  (≈ 20 проверок). Старые сценарии поправлены: кнопки «Сохранить в файл» и «В меню» — через меню «Мир»; перетаскивание
  к углу карты начинается не на ленте событий.
- **Нет регрессий**: кадры прежней версии (коммит `c67300d`) и новой сравнены пиксель в пиксель — сцены `data`,
  `clock` (день и ночь), галерея (`sprite=man`), эталон ×4, заставка на телефоне, испорченное сохранение на телефоне —
  **без единого отличия** (тексты переехали в модуль, не изменившись); `palette` — отличаются только числа спрайтов под
  цветами (новые значки). Карты с `ui=0` — пиксель в пиксель как `1.5/01…04`, `1.3/01-pair-x4`,
  `1.3/03-path-around-lake`; ×0,5 — те же 75 пикселей отличия от `1.2/`, что и раньше; заставка — как `0.8/01-title`.
- **Прогоны** (мир не менялся — отпечатки прежние): `npm run sim -- --seeds 1..100 --years 10` — `d9e731efb413a9a7`
  (как на 1.5), «Умерли при доступной еде и воде (ошибка ИИ)» — 0; `npm run sim -- --seeds 1..20 --years 1 --threads 1` —
  `38eaaedf6c040b5f` (как на 1.5), тик 1,7 мкс в среднем.
- **Производительность** (Chromium без видеокарты, окно 1280×720, мир 7, `--frame-time 4000`): ×2 на ×20 с выбранным
  жителем — 2,7 мс в среднем, 99 % ≤ 5,2 мс, 243 кадра за 4 с (60 в секунду); ×0,5 на ×20 — 6,9 / ≤ 11,7 мс; ×2 на ×1 —
  2,5 мс. Панель трогает страницу только при изменениях (дата — раз в тик, лента — при новом событии).

## Как устроено

- `src/ui/texts.ts` — все слова; импортирует только типы (загружается до таблиц данных: им пишет `src/main.ts` «Игра не
  запустилась»). Даты — `dateText(дата календаря, дней в сезоне)`; тик → слова — `src/ui/dates.ts` (`dateOf`, `shortDateOf`).
- `src/sim/save.ts` — `LoadError { code, reason, versions, detail }`, `LoadWarning { code }`; слова — `loadErrorText`,
  `loadWarningText`.
- `src/ui/feed.ts` — `createFeed()`: `update(world)` читает новые события журнала (каждое один раз), `entries` — 5 последних
  значимых с местом.
- `src/ui/hud.ts` — `createHud(ui, источник)`: полоса, лента, меню «Мир» (`hud.menu` — туда сцена кладёт панель
  сохранения), карточка, строки отладки (`hud.debug`). Источник (`HudSource`) — мир, цикл игры, выбор, полёт камеры,
  значки (`icon(имя, масштаб)` — спрайт на холсте точного размера).
- `src/app/mapView.ts` — выбор (`selected`, `select`, щелчок по жителю / мимо, Escape, `select=`), `flyToTile`,
  `flyToVillager`, кольца на месте; `src/render/selection.ts` — рамка и кольца пикселями мира (поверх света).
- `src/app/cameraControl.ts` — `flyTo(точка)`, `flying`; `window.__fc.camera.flying` — для проверок.
- Значки панели — спрайты `src/art/sprites/hud_*.ts` (12×12, вид `icon`).
- Адрес: `select=N`, `menu=1`.

## Решения и отступления

- ADR-026: модуль текстов, коды вместо слов в `src/sim`, устройство панели, лента, полёт, выбор.
- В ленте, кроме смерти (карточка: «пока — смерть с причиной»), — приход жителей, «голодает / мучается жаждой» и
  обморок: в новом мире лента не пуста, а голод предупреждает о смерти заранее.
- Меню «Мир» закрыто по умолчанию — оно нужно редко, а угол карты освобождается (`BACKLOG.md`, 1.1).
- Слова содержания (названия ресурсов, объектов, спрайтов) остались с содержанием; ошибки программиста в
  `src/render` — по-английски; сообщения проверки таблиц и названия показателей прогонов — для разработчика, на месте.
- Скорость, пауза и положение камеры по-прежнему не сохраняются (карточка: «по желанию» / «не запоминаются»).

## Известные проблемы и что отложено

- Лента — 5 строк, полной летописи нет (этап 3); полёт к событию не меняет ступень (на ×0,5 камера стоит, видны только
  кольца); слежения за жителем нет; полёт адресом не воспроизводится — `BACKLOG.md`, «Панель наблюдателя».
- Значки панели нарисованы впервые — **просьба к владельцу оценить** (месяц мелковат).
- «Подробности» под сообщением о плохом сохранении — технический текст по-английски (нарочно, для отчёта об ошибке).
- Классы панели сцены `clock` (`.hud`, `.hud-date`, `.hud-speed`) и панели наблюдателя не должны совпадать — на этом
  споткнулся шаг (сцена `clock` поменяла вид, поймано сравнением кадров): корень панели — `.observer`.

## Подсказки следующему шагу

- Новые слова — только в `src/ui/texts.ts`; новое действие жителя — ветка в `doingOf` (иначе не скомпилируется), её
  возьмут карточка и `debug=needs`.
- `select=N` — удобный способ снять крупно, что делает житель (рамка и карточка).
