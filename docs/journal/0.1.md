**Дата:** 2026-11-16 · **PR:** #1

## Что сделано

- Выбраны технологии: игра — веб-страница на TypeScript, отрисовка на Canvas 2D, графика описывается кодом
  (решения ADR-001…007 в `docs/DECISIONS.md`).

| Критерий из карточки | Выполнен | Чем подтверждён |
|----------------------|----------|-----------------|
| Игра собирается одной командой и открывается в браузере | да | `npm run build`; скриншоты заставки |

## Проверки

- `npm run check`: зелёный — линтер, типы, 9 тестов, дорожная карта (161 шаг), сборка.
- Скриншотер проверен и на отказ: неизвестная сцена (`?scene=nope`) даёт ошибку и ненулевой код выхода.
- Автозапуск сессии проверен: первый запуск ставит зависимости, повторный — пропускает установку.
- Разбиение GDD проверено скриптом: склейка файлов разделов совпадает с исходным текстом.

## Как устроено

- Запуск: `index.html` → `src/main.ts` → сцена из `src/app/scenes.ts` по параметру `scene`.
- Сцена — объект с `render(frame)` и `resize(w, h)` (`src/app/scene.ts`). Отрисовка — чистая функция номера кадра,
  поэтому `?frame=N` даёт всегда одинаковую картинку.
- Страница сообщает о готовности и ошибках через `window.__fc` — на это опирается `tools/screenshot.ts`.
- `tools/roadmap.ts` разбирает `docs/ROADMAP.md` (строки `- [ ] **0.2** …`) и карточки (`### 0.2 — …`).
  `check` требует для выполненного шага отчёт `docs/journal/<id>.md` и хотя бы один PNG в `docs/screenshots/<id>/`.
- `tests/architecture.test.ts` следит за чистотой `src/sim` и `src/data`.
- Biome не форматирует Markdown (исключён в `biome.json`): документы и GDD остаются под контролем автора.

## Решения и отступления

- ADR-001…007 в `docs/DECISIONS.md`. Главные: веб-стек; Canvas 2D без движка; графика как код; базовая графика
  уже на этапе 0 (вместо серых заглушек до этапа 5); дорожная карта GDD перенарезана под сессии.
- Версии GitHub Actions взяты последние на момент шага (checkout v7, setup-node v7, upload-artifact v7,
  upload-pages-artifact v5, deploy-pages v5).

## Известные проблемы и что отложено

- **Проверки в GitHub Actions не запустились**: аккаунт GitHub заблокирован из-за проблемы с оплатой
  («The job was not started because your account is locked due to a billing issue»). Задача завершается за 2 секунды
  без исполнителя и без лога, повторный запуск даёт то же. Все проверки пройдены локально, в том числе после чистой
  установки `npm ci`. Сами файлы `ci.yml` и `deploy.yml` поэтому ещё ни разу не выполнялись — их нужно будет
  проверить, когда Actions заработает (записано в `docs/BACKLOG.md`).
- GitHub Pages включается владельцем вручную (Settings → Pages → Source: GitHub Actions). До этого публикация
  пропускается без ошибки.
- Заставка — временная графика; визуальных проверок в CI нет (см. `docs/BACKLOG.md`).
