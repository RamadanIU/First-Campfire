# Шаг 0.5 — Таблицы данных: формат, загрузка, проверка

**Дата:** 2026-11-17 · **PR:** #6

## Что сделано

- **Три таблицы в `data/`**: `balance.json` — числа времени, движения и жизни из GDD §2.1 и §13.1;
  `resources.json` — **все 33 ресурса эпохи 0** из GDD §5.2 (10 видов еды, 12 материалов, 11 изделий) с категорией,
  эпохой, стопкой, сроком порчи и значком; `terrain.json` — 5 типов земли: проходимость, скорость, внешний вид.
- **Загрузчик с проверкой** (`src/data/`): одинаково работает в браузере, тестах и прогонах без графики. Ошибка в
  таблице называет файл, запись и поле, говорит, что ожидалось и что найдено, подсказывает опечатку
  («spoilDay — может быть, spoilDays?») и перечисляет все ошибки сразу, а не первую.
- **Ядро берёт время из таблицы**: длина суток, сезона, доли фаз суток больше не записаны в коде. История мира
  не изменилась — отпечатки миров зёрен 1, 2, 3 через миллион тиков те же, что до шага.
- **Значки всех ресурсов**: 32 новых спрайта 10×10 (ветки — готовый спрайт), новый вид спрайта «предмет».
- **Отладочная сцена `data`**: все ресурсы со значками на траве и параметрами, типы земли с тайлами, числа
  баланса с пояснениями. Страница собирается из таблиц: новая строка в `resources.json` появляется на ней сама.
- **Ошибки таблиц видны в игре**: испорченная таблица — красное окно «Игра не запустилась» со списком ошибок,
  битая ссылка на значок — предупреждение поверх сцены; скриншотер на обоих падает.

## Проверки

- `npm run check`: зелёный — линтер, типы, **349 тестов в 24 файлах** (было 229 в 21), дорожная карта, сборка.
- Прогон пустого мира `npm run bench` (Node, без сборки — таблицы читаются как JSON-модули): ≈ 3,3–3,6 млн тиков/с,
  хэши миров совпадают с замером до шага.
- Загрузка и проверка всех таблиц — ≈ 53 мкс (Node, среднее из 2000 повторов).
- Контрольные сцены: заставка, эталон ×2 и ×4, палитра, галерея, житель крупно, часы днём и ночью — сняты, ошибок
  на страницах нет, картинки как раньше (палитра: у значков нет «красных нулей», все цвета используются).
- Испорченная таблица и битая ссылка проверены в браузере (временная порча `resources.json`, затем файл возвращён):
  оба случая показаны на странице и роняют `npm run shot` с текстом ошибки.
- Прогоны `npm run sim` — с шага 0.6.

## Как устроено

- `data/balance.json`, `data/resources.json`, `data/terrain.json` — таблицы; одна запись — одна строка.
- `src/data/schema.ts` — маленькая библиотека схем: `int`, `num`, `bool`, `text`, `id`, `oneOf`, `ref`, `external`,
  `nullable`, `optional`, `obj`, `list`, `table`; `readTables`, `checkExternalRefs`, `DataError`, `formatIssue`.
- `src/data/tables.ts` — схемы таблиц с пояснением каждого поля, типы `Balance`, `Resource`, `Terrain`,
  `loadTables` (проверяет и замораживает). `src/data/index.ts` — импорт файлов и `DATA`.
- `src/app/dataRefs.ts` — проверка ссылок на спрайты и виды земли; `src/app/dataScene.ts` — сцена `data`.
- `src/main.ts` — игра загружается после того, как готов `window.__fc`, поэтому ошибка таблицы показывается на
  странице, а не оставляет пустой экран.
- `src/sim/calendar.ts` — `TIME` из таблицы; `DAY_PHASES` переехал в `src/data/tables.ts` (схеме нужны имена фаз).
- `src/art/sprite.ts` — вид `item`; `src/art/sprites/` — 32 новых файла-значка (`berries` … `fire_drill`).
- Подробно: `docs/ARCHITECTURE.md`, «Таблицы данных»; `docs/ART.md`, «Предметы».

## Решения и отступления

- **ADR-014**: таблицы — JSON-модули; своя проверка схем без библиотек; каждое поле обязательно, «нет значения» —
  явный `null`, лишнее поле — ошибка; внешние ссылки проверяет приложение; единицы — игровые (сутки, годы,
  проценты), еда — в рационах; вес выражен размером стопки (GDD §5.1 меряет грузоподъёмность стопками).
- **Стартовые числа, которых нет в GDD**: стопки всех ресурсов; порча орехов, грибов, яиц, жареного мяса; скорость
  по земле ×1,1 и по песку ×0,8. Записаны в ADR-014, будут настроены на шагах 1.4–1.11.
- `seasonsPerYear` не хранится в таблице: год — четыре сезона из списка в коде (это механика, а не число баланса).
- Для `data/**` ширина строки форматировщика — 160 знаков (`biome.json`), чтобы запись таблицы оставалась одной
  строкой. Проверки линтера не ослаблены.
- Порог подсказки опечаток: одна ошибка на три буквы — «fod» → food, «beries» → berries, но не «meat» → man.

## Известные проблемы и что отложено

- Значок «Шкура-накидка» читается слабее остальных (похож на меховой мешок), мёд похож на вафлю — `BACKLOG.md`.
- В GDD расходятся материалы шалаша (§13.3: жерди и лапник) и перечень ресурсов эпохи 0 (§5.2: палки и ветки) —
  `BACKLOG.md`, «Расхождения в GDD».
- Броды: мелкая вода пока непроходима (как требует карточка 1.3), хотя GDD §6.1 говорит о переходах вброд — `BACKLOG.md`.
- Русские окончания при числах считает сама сцена `data` — перенести в модуль текстов вместе с HUD (`BACKLOG.md`).
- Сохранения (0.7) не хранят таблицы: мир после загрузки живёт по текущим числам — пункт добавлен в карточку 0.7.
