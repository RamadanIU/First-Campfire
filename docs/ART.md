# Графика: спрайты как код

В репозитории нет файлов-картинок (ADR-003). Каждый спрайт — текстовый файл: картинка нарисована сеткой символов,
легенда говорит, какой символ каким цветом палитры красить. При запуске игры все спрайты превращаются в пиксели
и собираются в один холст-атлас. Формат и правила — ниже; обоснование — ADR-012 в `DECISIONS.md`.

## Где что лежит

| Файл | Что это |
|------|---------|
| `src/art/palette.ts` | Палитра: цвета рядами от тёмного к светлому (`RAMPS`), проверка палитры, подмена рядов |
| `src/art/sprite.ts` | Формат спрайта (`SpriteDef`, `defineSprite`), разбор сетки, проверка спрайта с понятными сообщениями |
| `src/art/sprites/<имя>.ts` | **Сами спрайты, по одному в файле** |
| `src/art/registry.ts` | Список всех спрайтов: собирает папку `sprites/` автоматически |
| `src/art/raster.ts` | Растеризатор: спрайт + палитра (+ подмена) → пиксели RGBA |
| `src/art/atlas.ts` | Упаковка всех кадров в один атлас (чистая функция) |
| `src/art/terrain.ts` | Виды земли (`TERRAIN_LOOKS`) и сборка тайла с переходами — см. «Земля и переходы» |
| `src/render/spriteSheet.ts` | Атлас на холсте, рисование кадра и тени по имени, кеш перекрашенных вариантов |
| `src/render/terrainLayer.ts` | Земля карты одной картинкой: тайлы с переходами, по холсту на каждое состояние ряби |
| `src/render/scenery.ts` | Сборка картинки: земля → тени → предметы по глубине → пузырьки |
| `src/app/galleryScene.ts` | Сцена `gallery` — просмотр всех спрайтов |
| `src/app/paletteScene.ts` | Сцена `palette` — мастер-палитра и перекраска жителей |
| `src/app/stylesheetScene.ts` | Сцена `stylesheet` — **эталон стиля**: стоянка у реки из спрайтов эпохи 0 |
| `src/app/dataScene.ts` | Сцена `data` — таблицы данных; значки ресурсов на тайле травы ×3 |

`src/art` не знает о браузере и зависит только от себя: там чистые функции, которые работают и в браузере,
и в тестах под Node. Холст и рисование — в `src/render` (проверяет `tests/architecture.test.ts`).

## Палитра

- Цвет называется **«ряд.номер»**: `grass.0` — самый тёмный цвет травы, `grass.3` — самый светлый.
  Номера в ряду идут **от тёмного к светлому** (тень → основной → блик); тест проверяет, что каждый следующий
  цвет светлее предыдущего.
- Цвета в палитре не повторяются, записываются `#rrggbb` строчными буквами.
- Это **мастер-палитра** (шаг 0.4, GDD §10.1): **69 цветов мира**, один полупрозрачный цвет тени и 3 служебных
  цвета отладочных экранов. Почему чуть больше 64 — ADR-013. Посмотреть: `?scene=palette` (под каждым цветом —
  сколько спрайтов его используют).
- Новый цвет добавляй, только если его нельзя заменить существующим: сначала посмотри `?scene=palette`.
  Сезонные и суточные ряды (осенняя листва, снег, ночь) — отдельные ряды для подмены, этап 1.10 и 5.

| Ряд | Цветов | Для чего |
|-----|--------|----------|
| `ink` | 1 | контур персонажей, глаза, буквы на значках (тёмный цветной, не чёрный) |
| `shadow` | 1 | тень под объектами; **полупрозрачный** (32 %), см. «Тени» |
| `grass` | 4 | трава земли; крона берёзы (желтеет осенью вместе с травой) |
| `dirt` | 3 | земля, тропа, стоянка |
| `sand` | 3 | песок, берег; `sand.0` — мокрая кромка у воды; свежий срез пня |
| `water` | 5 | `0–1` глубокая вода, `2–3` мелкая, `4` пена и блики |
| `stone` | 4 | камни, галька, кольцо костра; `stone.0` — контур камня и берёзы |
| `leaf` | 5 | листва деревьев и кустов; `leaf.0` — контур кроны, `leaf.4` — блик |
| `bark` | 4 | кора, древесина, ветки; `bark.0` — их контур; накидка из меха у мужчины |
| `berry` | 2 | ягоды |
| `fire` | 4 | пламя, искры, угли (огонь не затеняется — он сам свет) |
| `skin_pale`, `skin_light`, `skin_tan`, `skin_olive`, `skin_brown`, `skin_dark` | по 3 | шесть тонов кожи; одной длины — подменяют друг друга |
| `hair_black`, `hair_brown`, `hair_chestnut`, `hair_red`, `hair_blond` | по 2 | пять цветов волос; одной длины |
| `hide` | 3 | сыромятная кожа одежды, сухая трава шалаша |
| `bone` | 3 | кость и ракушки украшений, кора берёзы, бумага пузырьков |
| `ui` | 3 | служебные: фон и клетки отладочных экранов (не для спрайтов мира) |

У ряда может быть **прозрачность** (`alpha` от 0 до 1, не включая края): пиксели такого цвета просвечивают.
Сейчас полупрозрачен только `shadow`. Растеризатор сохраняет прозрачность ряда в пикселях.

## Перекраска

Перекраска — подмена **целого ряда** другим рядом той же длины, оттенок в оттенок:
`{ skin_light: 'skin_dark' }` рисует каждый пиксель `skin_light.N` цветом `skin_dark.N`.
Так делаются тона кожи, цвета волос, позже — сезоны (листва → осенняя листва) и крашеная одежда.
Подмена применяется один раз, не по цепочке: `{ a: 'b', b: 'a' }` меняет два ряда местами.

Спрайт рисуется в «основных» цветах (жители — кожа `skin_light`, волосы `hair_brown`), а варианты перечисляются
в поле `variants` —
их показывает галерея и проверяют тесты. В игре подмену передают при рисовании:
`sheet.draw(ctx, 'man', x, y, { swap: { skin_light: 'skin_dark', hair_brown: 'hair_red' } })`; перекрашенный вариант собирается
при первом обращении и дальше берётся из кеша.

## Формат спрайта

```ts
import { defineSprite } from '../sprite.ts';

export default defineSprite({
  name: 'stone',              // snake_case, совпадает с именем файла; на него ссылаются таблицы данных
  title: 'Камень',            // название для галереи
  kind: 'object',             // tile — тайл, object — объект, item — предмет, character — люди и звери, icon — значок
  width: 6,
  height: 4,
  anchor: { x: 3, y: 4 },     // точка, которая ставится в позицию объекта на карте
  legend: {
    o: 'bark.0',
    m: 'bark.2',
    l: 'bark.3',
  },
  animations: {
    idle: {                   // первая анимация — анимация по умолчанию
      frames: [
        `
        .oooo.
        olmmmo
        ommmmo
        .oooo.
        `,
      ],
      frameMs: 100,           // длительность кадра, мс: одно число или своё у каждого кадра
    },
  },
  variants: {                 // необязательно: перекраски для галереи
    mossy: { bark: 'leaf' },
  },
  shadow: { width: 6, height: 2, x: 1 },  // необязательно: тень-эллипс 6×2, центр сдвинут на 1 вправо
});
```

Правила сетки:

- Один символ — один пиксель. **`.` — всегда прозрачный** пиксель; переопределять его в легенде нельзя.
- Строки обрезаются по краям, поэтому сетку можно сдвигать отступом; пустые строки до и после сетки не считаются.
  Пробел внутри строки — ошибка (прозрачный пиксель пишется точкой).
- Число строк равно `height`, длина каждой строки — `width`.
- В легенде — по одному символу на цвет; каждый символ легенды должен встречаться хотя бы в одном кадре.
  Удобно: заглавная буква — светлее (`k` кожа, `K` кожа на свету), `o` — контур.
- Кадр можно повторить, сославшись на ту же строку-константу (`frames: [still, right, still, left]`).

Точка привязки (`anchor`): у человека — между ступнями на нижнем краю (`x: 6, y: 18` при 12×18), у дерева — основание
ствола, у тайла — левый верхний угол `0, 0`, у пузырька — кончик хвостика. Её можно ставить на правый и нижний край (значения до `width` и
`height` включительно). В галерее она отмечена крестиком.

Время анимации: игра показывает кадры с частотой 10 в секунду (`PRESENTATION_FPS`), поэтому длительности,
кратные 100 мс, выглядят точно. GDD §10.1: 4–8 кадров на цикл, «сочные» ключевые позы важнее плавности —
задержка на позе делается длинным `frameMs`, а не повтором кадров.

## Как добавить спрайт

1. Создать файл `src/art/sprites/<имя>.ts` (образец — выше или любой существующий спрайт). **Больше ничего
   править не нужно**: список спрайтов собирается из папки автоматически.
2. `npm test` — проверит спрайт. Ошибка называет спрайт, анимацию, кадр, строку и столбец, например:
   `спрайт «stone»: анимация «idle», кадр 1, строка 3: длина 7, ожидалось 6 (ширина спрайта) — «omsssso»`.
3. Посмотреть: `npm run dev` → `?scene=gallery` (все спрайты) или `?scene=gallery&sprite=<имя>` (один крупно:
   каждый кадр отдельно, варианты, легенда, точка привязки).
4. Снимок для оценки глазами: `npm run shot -- --out out/shots s="?scene=gallery&sprite=<имя>&frame=0"`.
   Параметр `frame=N` замораживает анимацию на моменте N × 100 мс; `ui=0` убирает подписи.

Большие спрайты (дерево) удобно сначала построить скриптом — например, крону из перекрывающихся шаров с освещением —
а потом доработать сетку руками. В репозиторий попадает только итоговая сетка.

## Правила стиля (GDD §10.1)

| Что | Правило |
|-----|---------|
| Проекция | Вид сверху под углом ¾: видны и крыши, и фасады |
| Размеры | Тайл 16×16; взрослый житель 12×18, лицо 6×6 |
| Палитра | Только цвета палитры (проверяет тест); перекраска — подменой рядов |
| Контур | Тёмный цветной (не чёрный) у персонажей и объектов; у земли и травы — **без контура** |
| Свет | Источник **слева-сверху**: блики слева-сверху, тени справа-снизу. Поэтому спрайты не зеркалят: смотрящий влево рисуется отдельно |
| Тени | Полупрозрачный эллипс под объектом (поле `shadow`), чуть вправо — см. «Тени» |
| Анимация | 4–8 кадров на цикл, 8–10 кадров/с; ключевые позы важнее плавности |
| Силуэт | Профессию и эпоху видно по силуэту и 2–3 цветам даже на дальнем зуме — проверяй спрайт на ×1 |
| Масштаб | Только целый (×1, ×2, ×4); сглаживание выключено; позиции — целые пиксели |
| Тайлы | Бесшовные: детали, уходящие за край, продолжаются с противоположной стороны; без ярких «предметов», выдающих повтор. Галерея показывает тайл замощённым 3×3 |

Порядок производства графики — GDD §10.7: сначала эталон эпохи 0 (шаг 0.4), сезоны и полный набор анимаций —
на этапе 5.

**Эталон стиля** — сцена `?scene=stylesheet` (×2 — `&zoom=2`, крупно — `&zoom=4`). Новую графику сравнивай с ней:
тот же свет, те же ряды палитры, такая же толщина контура, такой же размер деталей.

## Земля и переходы

Земля — тайлы 16×16 **без контура**. Вид земли (`TERRAIN_LOOKS` в `src/art/terrain.ts`) говорит, какими тайлами
он рисуется, как часто встречаются вариации, на каком он **слое** и как ведёт себя его край.

| Вид | Тайлы | Слой | Край |
|-----|-------|------|------|
| `deep_water` | `water_deep` (рябь 4 кадра) | 0 | — |
| `shallow_water` | `water_shallow` (рябь 4 кадра) | 1 | 4 ± 2 пикселя, плавный; пена `water.4` у суши |
| `sand` | `sand` | 2 | 3 ± 1,5, плавный; мокрая кромка `sand.0` у воды |
| `dirt` | `dirt` | 3 | 3 ± 2; мокрая кромка `dirt.0` у воды |
| `grass` | `grass`, `grass_2`, `grass_3` (5 : 3 : 2) | 4 | 3 ± 2, рваный (мелкое зерно) |

**Правило переходов.** Земля более высокого слоя **заходит** на соседний тайл более низкого слоя неровным краем
глубиной `depth ± jitter` пикселей; низкая на высокую не заходит никогда. Граница — функция **мировых координат
пикселя** (сглаженный шум), а не тайла: одна и та же граница одинаково видна с обеих сторон (нет швов) и не
повторяется вдоль длинного берега. Углы:

- **внешний угол** высокой земли (сосед по диагонали) — скруглён сам: расстояние до угловой точки;
- **внутренний угол** (одна и та же высокая земля с двух сторон) — закрывается дугой радиуса `round`,
  иначе низкая земля остаётся с квадратным углом и река выглядит лестницей;
- там, где суша касается воды, крайние пиксели суши — `shore` (мокрый песок), крайние пиксели воды — `foam`
  (пена, прерывистая: около 70 % линии).

Поэтому переходы не рисуются отдельными тайлами: на 5 видов земли хватает 7 тайлов. Новый вид земли — тайл
(или несколько вариаций) и строка в `TERRAIN_LOOKS` со своим слоем.

**Как рисовать тайл земли.** Основной цвет занимает большую часть тайла; детали — низкоконтрастные (травинка —
светлый кончик над тёмным основанием). Детали больше одного пикселя держи **на пиксель от краёв**: тогда любые
вариации и соседние тайлы стыкуются без шва. Одиночные пиксели можно ставить и на край.

**Вариации и вода.** Вариация тайла выбирается по его координатам (детерминированно, с весами). Анимированные
тайлы (вода) начинают с разных кадров — озеро не «мигает» целиком; у всех кадров одна длительность. Рябь тоже
держится вдали от краёв.

**Отрисовка.** `composeTerrainTile(art, at, x, y, timeMs)` — пиксели одного тайла (чистая функция).
`createTerrainLayer` собирает всю землю карты в холст, по одному на каждое состояние ряби (их 4), и кеширует;
`composeAll()` собирает их заранее, чтобы анимация не дёргалась. Тайл, окружённый такой же землёй, просто
копирует свою текстуру. Земля 64×64 со всеми состояниями собирается примерно за 0,35 с.

На карте вода должна быть связной по сторонам тайлов (а не только по диагонали): иначе мелководье, заходя
с двух сторон, перережет узкое место — так и задумано, но реку генератор (шаг 1.1) должен строить связной.

## Тени

Тень — **плоский полупрозрачный эллипс** на земле под объектом (GDD §10.1, «мягкие тени-пятна»). Задаётся полем
`shadow: { width, height, x?, y? }`: центр эллипса — точка привязки, сдвинутая на `x, y`. Свет слева-сверху,
поэтому тени чуть сдвинуты вправо (`x: 1–2`). Ширина — примерно ширина основания (у дерева — шире ствола,
меньше кроны), высота 3–6 пикселей. У тайлов и значков тени нет; у низких украшений (цветы, трава) — тоже.

Тени рисуются **отдельным слоем до всех объектов**: формы непрозрачно складываются в один холст, и он кладётся на
землю один раз с прозрачностью цвета `shadow.0` — перекрывающиеся тени не темнеют вдвойне и никогда не ложатся
на стоящие предметы. Это делает `createScenery` (`src/render/scenery.ts`); одиночную тень рисует
`sheet.drawShadow(ctx, имя, x, y, { scale })`.

## Жители

Взрослые эпохи 0 — спрайты `man` и `woman`, 12×18, лицо 6×6, точка привязки `6, 18`. Анимации:

| Анимация | Кадров | Что |
|----------|--------|-----|
| `idle_s`, `idle_n`, `idle_e`, `idle_w` | 2 (900 + 700 мс) | стоит и дышит: на выдохе голова и плечи на пиксель ниже |
| `walk_s`, `walk_n`, `walk_e`, `walk_w` | 4 × 200 мс | шаг (тело на пиксель ниже), проход, шаг другой ногой, проход |

`s` — лицом к зрителю, `n` — спиной, `e` — вправо, `w` — влево. **Влево — не зеркало вправо**: свет слева-сверху,
поэтому кадры `*_w` получены отражением `*_e` с обменом светлого и тёмного тона кожи (тест проверяет: силуэт
зеркальный, цвета — нет). Кожа — ряд `skin_light`, волосы — `hair_brown`; остальные 5 тонов кожи и 4 цвета волос —
подмены (`variants`), в игре их можно сочетать любые: `{ skin_light: 'skin_tan', hair_brown: 'hair_black' }`.

Одежда эпохи 0 (GDD §10.3): у мужчины — меховая накидка на плечах, ожерелье из зубов, набедренная повязка, борода;
у женщины — длинные волосы, платье из шкуры до колен, ожерелье из ракушек; оба босые.

## Предметы

Ресурс, лежащий на земле, — спрайт вида **`item`** (шаг 0.5). Тот же рисунок — значок ресурса в сцене `data`, а
позже в интерфейсе и в руках жителя. На спрайт ссылается таблица ресурсов: поле `sprite` в `data/resources.json`
(ветки используют готовый объект `branches`). Тест требует, чтобы у каждого спрайта-предмета был ресурс.

- Размер — **10×10** (вид `item` обязан помещаться в тайл 16×16), точка привязки — середина нижнего края `5, 9`.
- Без тени: предмет лежит на земле плоско.
- Контур тёмный: `ink.0` или самый тёмный цвет материала (`bark.0` у дерева, `stone.0` у камня); свет
  слева-сверху. Значок должен читаться на траве, земле и песке — проверяй в сцене `data` и в галерее на ×1.
- Узнаваемость — силуэтом и 2–3 цветами: ягоды — красная ягода с листиком, рыба — с раздвоенным хвостом,
  камни и орехи — горкой из трёх, хворост — вязанка, перетянутая полоской кожи, жареное мясо — окорок с костью.
- Материалы на значках — ряды палитры их вещества: дерево — `bark`, камень и кремень — `stone`, кожа и шкуры —
  `hide`, кость и береста — `bone`, лыко, жилы и трава — `sand`, мёд и смола — `fire`, яйца — `water` (голубые).

Все 33 ресурса эпохи 0: `?scene=data` (крупно, на траве) и раздел «Предметы» в `?scene=gallery`.

## Значки

Пузырьки мыслей (`kind: 'icon'`): `bubble_food`, `bubble_water`, `bubble_sleep` (буква Z плывёт вверх),
`bubble_cold`. 12×12, светлая «бумага» с тёмным контуром — читаются на траве, песке и воде. Точка привязки —
кончик хвостика: ставить на 2–3 пикселя выше макушки. Рисуются поверх всего (`over: true` в `scenery`).

## Сборка картинки

`createScenery(sheet, ширина, высота).draw(ctx, земля, предметы, timeMs)` рисует: землю → слой теней → предметы
и людей **по глубине** (чем больше `y` точки привязки, тем ближе к зрителю и тем позже рисуется; при равной
глубине — слева направо) → значки. У каждого предмета может быть свой сдвиг времени анимации (`phase`), чтобы
соседние деревья не качались в такт. Так собраны `stylesheet` и заставка; мир этапа 1 делает то же по чанкам.

**Ночь на заставке** — фильтр поверх картинки, а не палитра: всё умножается на синий «ночной» цвет, вокруг костра —
тёплый круг света ступенчатыми кольцами (пиксельный свет без плавного градиента); пламя рисуется после фильтра —
оно само свет. Настоящие сутки и свет костра в мире — шаги 1.5 и 1.9.
