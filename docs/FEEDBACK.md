# Отзывы владельца

Сюда сессии записывают замечания и пожелания владельца проекта — о внешнем виде, поведении жителей, интерфейсе,
приоритетах. Это второй по важности источник после GDD: отзыв учитывается в ближайшем подходящем шаге.

Формат записи:

```
## ГГГГ-ММ-ДД, шаг <id>
**Отзыв.** Что сказал владелец (близко к его словам).
**Решение.** Что сделано или куда запланировано (шаг / BACKLOG) — либо почему отклонено.
```

Новые записи — в конец.

## 2026-11-16, после шага 0.2
**Отзыв.** «Проверки на гитхаб никогда не заработают, не нужно вообще этим заниматься, как и публикацией,
а мержить нужно всегда самостоятельно, а не просить меня».
**Решение.** Правила изменены: ADR-011, `CLAUDE.md` (правила 5–6), `docs/PROCESS.md` (разделы 1, 5, 6),
навык `/step`, `README.md`. Файлы GitHub Actions удалены; сессии сами сливают свои PR.

## 2026-11-17, после шага 0.8
**Отзыв.** «Мне всё нравится визуально, так что этот вопрос закрытым можно считать. Светлячков мы оставляем в любом
случае… это маленькие животные, которые летают ночью… это одна из разнообразий игры. Зачем их убирать? Пусть они
существуют. Эти два вопроса можно навсегда закрытыми считать.»
**Решение.** (1) Стиль эпохи 0 (эталон `stylesheet`, заставка, галерея) **принят** — вопрос закрыт; графику дальше
рисуем в нём (`docs/ART.md`). (2) **Светлячки — постоянная часть мира**, не временная система (ADR-018; они есть и в
GDD §10.5 среди животных). Удаление из карточки 1.13 убрано; на шаге 1.5 (ночь и освещение) они переезжают с
отладочной сцены `clock` на карту: ночью рой светящихся точек над лугами и у воды.

## 2026-11-17, после шага 1.3
**Отзыв.** Ответы на вопросы отчёта о шагах 1.1–1.3: (1) ступени зума переключаются мгновенно — «не устраивает,
пусть будет плавным»; (2) с какого масштаба открывать мир — «×2 сделать основным»; (3) внешность первых двоих
(случайная по зерну) и темп их прогулок — «нравится»; (4) мелкая вода непроходима, и на тот берег реки, пересекающей
карту, не попасть, пока нет бродов, — «ок».
**Решение.** (1) **Зум плавный**: картинка за 0,25 с перетекает к следующей ступени, точка под курсором (пальцами,
центр экрана для клавиш) в каждом кадре остаётся на месте; на мгновение перехода пиксели чуть разной ширины, ступень,
к которой пришли, снова резкая (ADR-022 заменяет пункт ADR-020). (2) **Мир без `zoom=` открывается на ×2** «улица» —
основной вид GDD §10.1 (ADR-022). (3) Внешность и темп оставлены как есть — вопрос закрыт. (4) Принято: мосты и броды —
шаг 7.5 по плану.
