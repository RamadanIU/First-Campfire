# Отзывы владельца

Сюда сессии записывают замечания и пожелания владельца проекта — о внешнем виде, поведении жителей, интерфейсе,
приоритетах. Это второй по важности источник после GDD: отзыв учитывается в ближайшем подходящем шаге.

Формат записи:

```
## ГГГГ-ММ-ДД, шаг <id>
**Отзыв.** Что сказал владелец (близко к его словам).
**Решение.** Что сделано или куда запланировано (шаг / BACKLOG) — либо почему отклонено.
```

Новые записи — в конец.

## 2026-11-16, после шага 0.2
**Отзыв.** «Проверки на гитхаб никогда не заработают, не нужно вообще этим заниматься, как и публикацией,
а мержить нужно всегда самостоятельно, а не просить меня».
**Решение.** Правила изменены: ADR-011, `CLAUDE.md` (правила 5–6), `docs/PROCESS.md` (разделы 1, 5, 6),
навык `/step`, `README.md`. Файлы GitHub Actions удалены; сессии сами сливают свои PR.
